# AutoDev Agency - Website Starter

موقع شركة AutoDev Agency مطابق للتصميم المطلوب.

## الملفات المتوفرة

```
autodev/
├── index.html              ← الصفحة الرئيسية
├── assets/                 ← الشعارات وصور المشاريع
├── portfolio/              ← صفحة البورتفوليو الكاملة
│   ├── index.html
│   ├── data.js             ← محتوى المشاريع المحلي
│   ├── config.js           ← إعدادات Supabase (اختياري)
│   └── ...
└── dashboard/              ← لوحة التحكم الكاملة ★
    ├── index.html
    ├── css/dashboard.css
    ├── js/api.js           ← طبقة البيانات (جاهزة للربط لاحقاً)
    ├── js/app.js
    └── README.md
```

## طريقة التشغيل

1. افتح `index.html` مباشرة في المتصفح.
2. أو استخدم Live Server في VS Code / Cursor.
3. لوحة التحكم: افتح `dashboard/index.html`

## لوحة التحكم (Dashboard)

لوحة تحكم احترافية كاملة تشمل:

- **نظرة عامة** — إحصائيات + رسوم بيانية
- **الطلبات** — استقبال وإدارة طلبات العملاء
- **العملاء** — إدارة قاعدة العملاء والإيرادات
- **المشاريع** — إدارة البورتفوليو (متعدد اللغات)
- **الشركاء** + **عقود الشراكة**
- **الإعلانات** — حملات + ميزانيات + أداء
- **الرسائل** — رسائل نموذج التواصل
- **الخدمات** + **الإعدادات**

البيانات حالياً محلية (localStorage) مع بيانات تجريبية جاهزة.  
عند الربط مع Backend لاحقاً: غيّر فقط `dashboard/js/api.js` — الواجهة جاهزة.
